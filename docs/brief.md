I want to transform this existing **Arabic RTL Fintech Landing Page** into a modern Arabic web application for planning and tracking **قضاء الصلوات الفائتة**.

## Project concept

This website is designed for Muslims who want to estimate missed prayers from a past period, create a realistic plan to make them up gradually, track their progress, and optionally generate a printable PDF planner.

The experience should feel peaceful, private, simple, encouraging, and respectful.

This is NOT a social network and there are NO user accounts or profiles.

User data and progress will be stored locally in the browser, so privacy should be an important part of the experience.

## Important design instruction

Use the **existing Figma template as the visual foundation**.

Keep and reuse as much as possible:

* overall visual style
* Arabic RTL layout
* typography hierarchy
* spacing system
* grid
* card style
* border radius
* button system
* navigation structure
* responsive behavior
* section rhythm
* existing components when appropriate

However, do NOT simply replace fintech text with prayer-related text.

Adapt each section intelligently to the new product and redesign components where necessary.

Remove any fintech-specific elements that no longer make sense.

The result should feel like this template was originally designed for this product.

## Language and direction

The primary interface language is **Arabic**.

Use proper **RTL layout** throughout the website.

Use clear, natural Modern Standard Arabic.

Avoid overly formal or complicated religious language.

The tone should be calm, supportive, respectful, and non-judgmental.

## Visual direction

Keep the sophistication and cleanliness of the original template, but adapt its emotional tone to this project.

The design should feel:

* peaceful
* modern
* minimal
* trustworthy
* warm
* premium but accessible
* spacious
* respectful

Avoid stereotypical Islamic visual design.

Do NOT fill the page with:

* mosque silhouettes
* crescents everywhere
* excessive Islamic patterns
* bright green gradients
* gold ornaments everywhere

A subtle Islamic identity is enough.

Prefer a sophisticated palette based on:

* warm off-white / cream backgrounds
* deep muted green
* neutral charcoal text
* subtle sand or warm accent tones

Keep strong accessibility and contrast.

## UX principle

The user may arrive feeling overwhelmed because they potentially have thousands of missed prayers.

The design must transform that feeling from:

**"لدي آلاف الصلوات التي يجب أن أقضيها"**

into:

**"لدي خطة واضحة لما أستطيع القيام به اليوم."**

Do not emphasize huge debt numbers aggressively.

Focus on manageable daily actions, gradual progress, flexibility, and clarity.
